# Telegram Multi-Channel Deduplicator

Система семантической дедупликации сообщений из нескольких Telegram каналов на основе LLM embeddings.

## Особенности

- **Семантический анализ**: определяет дубликаты даже при разной формулировке
- **Быстрая обработка**: использует SemHash для эффективной дедупликации
- **Real-time**: обрабатывает сообщения в режиме реального времени
- **Настраиваемый порог**: гибкая настройка чувствительности
- **Статистика**: отслеживание количества дубликатов

## Установка

1. Клонируйте репозиторий:
```bash
git clone <your-repo>
cd deduplicate
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте конфигурацию:
```bash
cp .env.example .env
```

4. Заполните `.env` файл:
   - Получите API credentials на https://my.telegram.org/apps
   - Узнайте ID каналов через @username_to_id_bot

## Использование

### 1. Базовый дедупликатор (рекомендуется для начала)

```bash
python telegram_deduplicator.py
```

Использует SemHash для быстрой семантической дедупликации. Идеален для начала работы.

### 2. Продвинутый дедупликатор

```bash
python advanced_deduplicator.py
```

Дополнительные возможности:
- Sentence Transformers с кастомными моделями
- Qdrant для персистентности
- LLM-верификация для edge cases (опционально)
- Мультиязычная поддержка

### 3. Тестирование методов

Протестируйте разные методы дедупликации без подключения к Telegram:

```bash
python test_deduplication.py
```

Сравнивает MD5 Hash, SemHash и Sentence Transformers на реальных примерах.

### Тестовый режим (без пересылки)

Оставьте `TARGET_CHANNEL` пустым в `.env` - сообщения будут только логироваться.

### Примеры

#### Пример 1: Криптоновости

Источники: CryptoNews, Bitcoin24, CoinDesk
→ Агрегация в единый канал без дубликатов

#### Пример 2: Новостные агрегаторы

Источники: РИА, ТАСС, Интерфакс
→ Уникальные новости в один канал

## Настройка порога схожести

В `.env` измените `SIMILARITY_THRESHOLD`:

- `0.95` - консервативный (только почти идентичные)
- `0.85` - сбалансированный ✅ (рекомендуется)
- `0.75` - агрессивный (ловит больше дубликатов)

## Архитектура

```
Source Channels → Telethon Listener → SemHash Deduplication → Target Channel
                                             ↓
                                      Message History
                                     (sliding window)
```

## FAQ

**Q: Как получить ID канала?**
A: Используйте бота @username_to_id_bot в Telegram

**Q: Работает ли с приватными каналами?**
A: Да, если ваш аккаунт имеет доступ

**Q: Можно ли обрабатывать изображения?**
A: Текущая версия только для текста. Для медиа см. perceptual hashing

**Q: Сколько каналов можно агрегировать?**
A: Неограниченно, но рекомендуется до 50 для оптимальной производительности

## Производительность

- **Скорость**: ~200 сообщений/сек
- **Память**: ~500MB для 10K сообщений в истории
- **Точность**: 95%+ (зависит от порога)
