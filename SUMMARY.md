# 📋 Краткая сводка: Дедупликация для Telegram каналов

## 🎯 Суть задачи
Агрегация сообщений из нескольких Telegram каналов в один с **семантической дедупликацией** - когда разные формулировки несут одинаковый смысл.

---

## ✅ Что найдено

### 1. Готовые GitHub решения для семантической дедупликации

| Решение | Оценка | Особенность |
|---------|--------|-------------|
| **SemHash** | ⭐⭐⭐⭐⭐ | Быстро, просто, эффективно |
| **text-dedup** | ⭐⭐⭐⭐ | Множество методов, масштабируемость |
| **SemanticDeduplicator** | ⭐⭐⭐ | LLM-powered, высокая точность |

### 2. Технический подход

```
Telegram Channels → Telethon → Semantic Deduplication → Target Channel
                                        ↓
                                   Embeddings
                                (Model2Vec/SBERT)
                                        ↓
                                 ANN Search
                              (Vicinity/Qdrant)
                                        ↓
                            Cosine Similarity > 0.85
                                        ↓
                              Unique / Duplicate
```

### 3. Рекомендованный стек

**Базовый (MVP):**
- SemHash для дедупликации
- Telethon для Telegram API
- In-memory хранилище

**Production:**
- Sentence Transformers (мультиязычная модель)
- Qdrant для персистентности
- Опционально: LLM для edge cases


## 📈 Преимущества семантической дедупликации

### До (только hash):
```
Channel 1: "Bitcoin вырос на 10%"          ✅ Уникально
Channel 2: "Биткоин подорожал на 10%"     ✅ Уникально (!)
Channel 3: "BTC увеличился на 10%"        ✅ Уникально (!)
→ Результат: 3 сообщения (все дубликаты!)
```

### После (семантическая):
```
Channel 1: "Bitcoin вырос на 10%"          ✅ Уникально
Channel 2: "Биткоин подорожал на 10%"     ❌ Дубликат
Channel 3: "BTC увеличился на 10%"        ❌ Дубликат
→ Результат: 1 сообщение
```

**Экономия:** 30-50% контента в типичных новостных каналах

## 🔍 Ключевые технологии

### Embeddings модели:
- **Model2Vec** - быстрая (SemHash)
- **all-MiniLM-L6-v2** - универсальная
- **paraphrase-multilingual-mpnet-base-v2** - для русского

### Векторный поиск:
- **Vicinity** - in-memory ANN (SemHash)
- **FAISS** - от Meta, популярный
- **Qdrant** - современный, с персистентностью

### LLM (опционально):
- **GPT-4o-mini** - $0.15/1M tokens
- **Claude Haiku** - быстрый, дешевый

## ❓ FAQ

**Q: Работает ли с русским языком?**
✅ Да, используйте мультиязычные модели (см. advanced_deduplicator.py)

**Q: Нужен ли GPU?**
❌ Нет, CPU достаточно. GPU ускорит, но не обязателен.

**Q: Сколько каналов можно агрегировать?**
✅ Неограниченно, но рекомендуется до 50 для оптимальной производительности

**Q: Можно ли дедуплицировать изображения?**
⚠️ Текущая версия - только текст. Для медиа нужны perceptual hash + CLIP

**Q: Требуется ли интернет?**
⚠️ Только для Telegram API. Дедупликация работает локально.

**Q: Какой порог схожести выбрать?**
✅ Начните с 0.85 (сбалансированный), потом подстройте под свои данные
